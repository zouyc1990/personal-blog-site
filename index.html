Learning System

云原生能力地图

目标不是收藏链接，而是四周内能读懂生产环境：本质是什么、底层架构如何分层、适合什么场景、关键组件背后用了哪些算法和数学原理。

4 Week Route

  1. 第 1 周：容器交付能写 Dockerfile、解释镜像分层、定位容器启动失败。
  2. 第 2 周：K8s 编排能部署服务、暴露流量、看懂事件、处理 Pending 和 CrashLoop。
  3. 第 3 周：中间件链路能设计缓存、队列、网关、限流和积压处理策略。
  4. 第 4 周：数据库治理能看执行计划、分析锁等待、设计备份恢复和容量策略。

Done Means

学完要能做三件事

  • 能用一句话讲清容器、K8s、中间件、数据库的本质。
  • 能画出从 Ingress 到数据库的架构链路和故障边界。
  • 能说出调度、缓存、队列、索引、复制背后的核心算法。
Containers

容器：把应用变成可交付单元

学习重点是镜像构建、运行时隔离、网络和数据卷，而不是背 Docker 命令。

能力树

  • Dockerfile、多阶段构建、镜像分层
  • 进程、namespace、cgroup、非 root 运行
  • bridge 网络、端口映射、volume、registry

原理层

  • 本质：进程隔离 + 文件系统快照 + 资源约束
  • 架构：镜像、registry、runtime、kernel、network
  • 算法：Merkle/DAG、hash、copy-on-write、CFS

实操任务

  • 构建一个 Web 镜像并压到 150MB 内
  • 用 Compose 启动 Web、Redis、PostgreSQL
  • 制造 OOM 和端口冲突并定位原因
  • Docker Docs
  • Dockerfile
  • Docker Compose
  • Docker Security
Kubernetes

K8s：把期望状态落到集群

学习重点是对象模型、控制器和排障链路：API Server、etcd、Controller、Scheduler、Kubelet。

能力树

  • Pod、Deployment、StatefulSet、DaemonSet
  • Service、Ingress、DNS、CNI、NetworkPolicy
  • ConfigMap、Secret、PVC、RBAC、HPA

原理层

  • 本质：声明式 API + 控制器反馈回路
  • 架构：API Server、etcd、Scheduler、Controller、Kubelet
  • 算法：Raft、调度打分、bin packing、指数退避

排障入口

  • Pending：资源、污点、亲和性、PVC
  • CrashLoop：命令、配置、探针、依赖
  • 不可访问：Service、Endpoint、DNS、网络策略
  • Kubernetes Concepts
  • Kubernetes Tasks
  • Helm Docs
  • etcd Docs
Middleware

中间件：控制流量、削峰和依赖失败

学习重点是语义：缓存一致性、消息确认、消费幂等、限流、熔断和积压恢复。

能力树

  • Redis：缓存、锁、过期、淘汰、持久化
  • Kafka/RabbitMQ：分区、确认、重试、死信
  • NGINX：代理、超时、重试、限流、TLS

原理层

  • 本质：时间、流量、状态和依赖的缓冲层
  • 架构：client、broker/proxy、存储、复制、消费组
  • 算法：一致性哈希、LRU/LFU、日志追加、令牌桶

生产问题

  • 缓存穿透、击穿、雪崩和热点 key
  • 消息重复、乱序、积压和消费者抖动
  • 网关 502/504、连接耗尽和重试放大
  • Redis Docs
  • Kafka Documentation
  • RabbitMQ Docs
  • NGINX Docs
Database

数据库：保证查询、事务和恢复

学习重点是数据生命周期：建模、索引、事务、锁、复制、备份、恢复和容量治理。

能力树

  • SQL、索引、执行计划、统计信息
  • 事务隔离、MVCC、锁等待、死锁
  • WAL/binlog、复制延迟、备份恢复、RPO/RTO

原理层

  • 本质：持久化状态 + 查询优化 + 并发控制
  • 架构：SQL 层、优化器、执行器、缓存、存储引擎、日志
  • 算法：B+Tree、LSM、MVCC、WAL、两阶段提交

实战检查

  • 慢查询：扫描行数、回表、排序、join
  • 故障恢复：全量备份、增量日志、恢复演练
  • 容量：增长率、冷热数据、归档和分区
  • PostgreSQL Docs
  • MySQL 8.4 Reference
  • MongoDB Manual
  • PostgreSQL Tutorial
